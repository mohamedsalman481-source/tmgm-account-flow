# TMGM · Account Opening Flow (EN / AR)

Interactive bilingual guide: how to open a TMGM live account — 5 stages, 11 steps.
دليل تفاعلي ثنائي اللغة لفتح حساب حقيقي لدى TMGM — ٥ مراحل و١١ خطوة.

Single static file (`index.html`), no build step.

## Deep links
- `#en` / `#ar` — open in a language
- `#step-4-ar` — jump to step 4 in Arabic
- `#stage-2-en` — jump to stage 2 in English

## Publish on GitHub Pages
1. Create a new repo (e.g. `tmgm-account-flow`) and upload `index.html` and `.nojekyll`.
2. Repo → Settings → Pages → Source: *Deploy from a branch* → `main` / `(root)` → Save.
3. Your link: `https://<your-username>.github.io/tmgm-account-flow/`
